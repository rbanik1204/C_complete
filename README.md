## 📖 Introduction  

This repository contains my **C programming practice codes and projects**.  
It serves as a **learning journal** where I explore different concepts of the C language, from basic syntax to advanced topics like **pointers, dynamic memory allocation, data structures, and file handling**.  

The purpose of this repo is to:  
- Practice **problem-solving in C**  
- Build a strong foundation for **system programming**  
- Understand **low-level concepts** like memory management
